# Modified Huffman Compression & Decompression

## 📌 Overview

A Python implementation of the Modified Huffman Coding algorithm for lossless data compression. The project compresses files into binary format and decompresses them to recover the original data.

## ✨ Features

* Read input from files.
* Calculate symbol probabilities.
* Generate Huffman codes.
* Compress data and save it in binary format.
* Decompress files and verify data integrity.
* Accept a minimum symbol probability as input.
